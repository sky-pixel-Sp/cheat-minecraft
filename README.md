# SkyOP Client — Minecraft Java 26.3

Fabric client-side mod source and automated GitHub Actions build. The project targets Minecraft 26.3, Fabric Loader 0.20.1, Fabric API 0.165.2+26.3, Java 25, Fabric Loom 1.18.4 and Gradle 9.7.1.

The GitHub Actions workflow will compile the project, verify the remapped JAR and publish it as the `SkyOP-Client-Minecraft-26.3` artifact. See the Actions tab for build status and downloads.
